# 安全配置与加固指南

## 🛡️ 系统安全配置与加固 - 建立安全底线

### 📋 当前安全风险

#### 1. 硬编码密码问题
- **docker.env**: `MYSQL_ROOT_PASSWORD=123456` (弱密码)
- **application-local.yaml**: `password: 123456` (硬编码密码)
- **docker-compose.yml**: 默认密码 `123456`
- **admin用户**: 密码为 `admin123` (弱密码)
- **初始化密码**: 系统配置为 `123456` (弱密码)

#### 2. 敏感信息暴露
- **SecurityProperties**: `mockSecret = "test"` (默认测试密钥)
- **env.example**: 包含示例密码和密钥
- **Mock模式**: 默认启用，生产环境风险

#### 3. 安全配置问题
- **密码加密**: 使用BCrypt，强度可优化
- **访问控制**: 缺乏强密码策略
- **测试用户**: 多个测试账号使用弱密码

### 🔧 安全配置修复方案

#### 1. 环境变量化敏感信息

**生产环境配置 (.env.production)**:
```bash
# 数据库密码 - 必须使用强密码
MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD}

# JWT密钥 - 必须使用强密钥
JWT_SECRET=${JWT_SECRET}

# Redis密码 - 生产环境建议开启
REDIS_PASSWORD=${REDIS_PASSWORD}

# Mock密钥 - 生产环境应禁用
MOCK_SECRET=${MOCK_SECRET}
```

#### 2. 配置文件安全化

**application-local.yaml 修改**:
```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          username: root
          password: ${MASTER_DATASOURCE_PASSWORD:123456}  # 使用环境变量
        slave:
          username: root
          password: ${SLAVE_DATASOURCE_PASSWORD:123456}   # 使用环境变量
```

**docker-compose.yml 修改**:
```yaml
environment:
  - MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD:-your-secure-password}
  - JWT_SECRET=${JWT_SECRET:-your-jwt-secret}
  - REDIS_PASSWORD=${REDIS_PASSWORD:-your-redis-password}
```

#### 3. 安全配置类优化

**SecurityProperties.java 修改**:
```java
@ConfigurationProperties(prefix = "medicine.security")
@Validated
@Data
public class SecurityProperties {
    
    /**
     * mock 模式的开关
     */
    @NotNull(message = "mock 模式的开关不能为空")
    private Boolean mockEnable = false;
    
    /**
     * mock 模式的密钥
     * 生产环境必须配置强密钥
     */
    @NotEmpty(message = "mock 模式的密钥不能为空")
    private String mockSecret = "${MOCK_SECRET:test}";  // 使用环境变量
    
    /**
     * 密码策略配置
     */
    private PasswordPolicy passwordPolicy = new PasswordPolicy();
    
    /**
     * 密码策略
     */
    @Data
    public static class PasswordPolicy {
        /**
         * 最小长度
         */
        private Integer minLength = 12;
        
        /**
         * 需要大写字母
         */
        private Boolean requireUppercase = true;
        
        /**
         * 需要小写字母
         */
        private Boolean requireLowercase = true;
        
        /**
         * 需要数字
         */
        private Boolean requireDigit = true;
        
        /**
         * 需要特殊字符
         */
        private Boolean requireSpecialChar = true;
        
        /**
         * 密码有效期（天）
         */
        private Integer expirationDays = 90;
    }
}
```

### 🔒 安全加固方案

#### 1. 强密码策略

**密码要求**:
- 最小长度: 12位
- 包含大写字母、小写字母、数字、特殊字符
- 不能使用常见弱密码
- 定期更换 (90天)

**示例强密码**:
```
Admin@2024!Secure
Medicine#2024$Strong
Pharmacy@123!Safe
```

#### 2. 用户密码更新

**更新admin用户密码**:
```sql
-- 更新admin用户密码为强密码
UPDATE system_users 
SET password = '$2a$10$YourStrongPasswordHashHere' 
WHERE username = 'admin' AND tenant_id = 1;

-- 更新系统初始化密码配置
UPDATE infra_config 
SET value = 'Admin@2024!Secure' 
WHERE config_key = 'sys.user.init-password';

-- 禁用测试用户
UPDATE system_users 
SET status = 1 
WHERE username IN ('test', 'medicine', 'yuanma') AND tenant_id = 1;
```

#### 3. 密码验证器实现

```java
@Component
public class PasswordValidator {
    
    public boolean validatePassword(String password) {
        // 长度检查
        if (password.length() < 12) return false;
        
        // 复杂度检查
        boolean hasUpper = password.chars().anyMatch(Character::isUpperCase);
        boolean hasLower = password.chars().anyMatch(Character::isLowerCase);
        boolean hasDigit = password.chars().anyMatch(Character::isDigit);
        boolean hasSpecial = password.chars().anyMatch(c -> "!@#$%^&*()_+-=[]{}|;:,.<>?".indexOf(c) >= 0);
        
        return hasUpper && hasLower && hasDigit && hasSpecial;
    }
}
```

### 🛡️ 安全最佳实践

#### 1. 密码策略
- **最小长度**: 12位
- **复杂度要求**: 包含大小写字母、数字、特殊字符
- **定期更换**: 90天更换一次
- **禁止重复**: 不能使用历史密码

#### 2. 密钥管理
- **JWT密钥**: 使用256位随机字符串
- **加密密钥**: 使用环境变量或密钥管理服务
- **API密钥**: 定期轮换

#### 3. 环境隔离
- **开发环境**: 使用测试密码
- **测试环境**: 使用独立密码
- **生产环境**: 使用强密码，禁止硬编码
