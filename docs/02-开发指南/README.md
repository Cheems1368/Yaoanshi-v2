## 🏗️ 技术架构

### 核心技术栈
- **后端框架**: Spring Boot 2.7.18
- **数据库**: MySQL 8.0
- **缓存**: Redis 6.x
- **安全**: Spring Security + JWT
- **监控**: Spring Boot Actuator + Prometheus

### 架构特点
- **模块化设计**: 6个核心业务模块，易于扩展
- **分层架构**: Controller-Service-Mapper分层
- **缓存策略**: 多级缓存，提升性能
- **安全机制**: JWT认证，RBAC权限控制

## 💻 核心功能

### 1. 患者档案管理
- 档案分层管理（红/黄/蓝层）
- 完整度评分算法
- 合规校验规则引擎

### 2. 用药计划管理
- 智能用药计划生成
- 计划执行跟踪
- 状态机管理

### 3. 用药打卡记录
- 打卡流程（提交→撤销→核实）
- 防重复提交机制
- 状态管理

### 4. 依从性统计
- 7/30/90天统计计算
- 常用药品Top统计
- 批量计算和重新计算

### 5. 报告生成
- 7/30/90天报告生成
- 季度报告生成
- 报告导出功能（PDF）

### 6. 提醒通知
- 多渠道通知（短信/语音/邮件）
- 智能提醒调度
- 通知模板管理

## 📚 开发规范

### 代码规范
- 遵循阿里巴巴Java开发手册
- 使用Lombok简化代码
- 统一异常处理机制
- 完善的日志记录

### 测试规范
- 单元测试覆盖核心业务逻辑
- 集成测试验证接口功能
- 测试覆盖率 ≥ 60%

### 质量门禁
- 静态代码检查（Checkstyle、SpotBugs、PMD）
- 测试覆盖率检查（JaCoCo）
- 依赖安全检查（OWASP）
