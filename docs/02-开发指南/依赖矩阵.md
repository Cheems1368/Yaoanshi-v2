## 模块依赖关系

### 基础模块
- `medicine-dependencies` - 依赖管理
- `medicine-framework` - 框架组件

### 业务模块
- `medicine-module-system` - 系统管理
- `medicine-module-infra` - 基础设施
- `medicine-module-drug` - 药品管理
- `medicine-module-patient` - 患者管理
- `medicine-module-medication` - 用药管理

### 聚合模块
- `medicine-server` - 应用启动

## 编译顺序建议

1. `medicine-dependencies` → `medicine-framework`（基础）
2. `medicine-module-system` → `medicine-module-infra`（系统）
3. `medicine-module-drug` → `medicine-module-patient`（业务）
4. `medicine-module-medication`（用药）
5. `medicine-server`（聚合启动）

## 命令示例

```bash
# 单模块带依赖编译
mvn -q -DskipTests -pl :medication -am package

# 多模块串行编译
mvn -q -DskipTests -pl :module-a,:module-b -am package

# 全项目编译
mvn -q -DskipTests package
```

## 版本管理策略

- 主要依赖版本在 `medicine-dependencies` 中统一管理
- 特殊版本依赖在具体模块中明确声明
- 使用 Spring Boot BOM 管理 Spring 生态版本
- MapStruct 和 Lombok 版本保持一致性
