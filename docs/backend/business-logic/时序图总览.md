## 🎯 关键业务规则

### 1. 工单处理规则
- 工单必须按状态顺序流转，不能跳跃
- 只有特定状态才能进行特定操作
- 工单被驳回后不能继续处理
- 工单完成后不能修改

### 2. 处方管理规则
- 处方必须经过医生签名才能生效
- 药师必须审核处方才能配药
- 处方有有效期限制（默认7天）
- 处方状态和配药状态分别管理

### 3. 用药计划规则
- 用药计划必须包含至少一个计划项
- 今日待办任务基于计划项自动生成
- 患者打卡需要防重复提交
- 打卡记录需要医生/药师验证

### 4. 权限控制规则
- 不同角色有不同的操作权限
- 患者只能操作自己的数据
- 药师可以处理分配给自己的工单
- 医生可以处理升级给自己的工单
