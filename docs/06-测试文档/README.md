## 🧪 测试类型

### 1. 单元测试
- 核心业务逻辑测试
- 服务层测试
- 工具类测试
- 测试覆盖率 ≥ 60%

### 2. 集成测试
- 接口功能测试
- 数据库集成测试
- 缓存集成测试

### 3. 冒烟测试
- 核心功能验证
- 健康检查验证
- 基础流程验证

### 4. 性能测试
- 接口响应时间测试
- 并发性能测试
- 数据库性能测试

## 🚀 快速开始

### 运行单元测试
```bash
# 运行所有测试
mvn test

# 运行特定模块测试
mvn test -pl medicine-module-medication

# 生成测试覆盖率报告
mvn test jacoco:report
```

### 运行冒烟测试
```bash
# 使用PowerShell脚本
.\scripts\smoke-test.ps1

# 使用HTTP测试
curl http://localhost:48080/actuator/health
```
