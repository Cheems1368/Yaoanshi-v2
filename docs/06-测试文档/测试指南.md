# 测试指南

本文档提供测试流程、冒烟测试和单元测试的详细指南。

## 🎯 测试目标

不依赖前端即可自测关键业务链，确保系统功能正常。

## 📋 测试类型

### 1. 单元测试

#### 测试范围
- 核心业务逻辑测试
- 服务层测试
- 工具类测试
- 数据访问层测试

#### 测试规范
- 测试覆盖率 ≥ 60%
- 使用JUnit 5 + Mockito
- 遵循AAA模式（Arrange-Act-Assert）
- 测试方法命名：`should_ExpectedBehavior_When_StateUnderTest`

#### 运行测试
```bash
# 运行所有测试
mvn test

# 运行特定模块测试
mvn test -pl medicine-module-medication

# 生成测试覆盖率报告
mvn test jacoco:report
```

### 2. 集成测试

#### 测试范围
- 接口功能测试
- 数据库集成测试
- 缓存集成测试
- 外部服务集成测试

#### 测试环境
- 使用测试数据库
- Mock外部服务
- 使用测试配置

### 3. 冒烟测试

#### 测试流程

**1. 环境准备**
```bash
# 启动所有服务
docker compose up -d

# 等待服务启动（约30-60秒）
docker compose ps
```

**2. 健康检查**
```bash
# 检查应用健康状态
curl http://localhost:48080/actuator/health

# 检查数据库连接
curl http://localhost:48080/actuator/health/db

# 检查Redis连接
curl http://localhost:48080/actuator/health/redis
```

**3. 认证流程**
```bash
# 登录获取token
curl -X POST "http://localhost:48080/admin-api/system/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"000000"}'
```

**4. 核心接口测试**
- 患者档案查询
- 用药计划创建
- 打卡记录提交
- 依从性统计查询

#### 使用测试脚本
```powershell
# 运行冒烟测试脚本
.\scripts\smoke-test.ps1

# 指定服务器URL
.\scripts\smoke-test.ps1 -BaseUrl "http://localhost:48080"
```

### 4. 性能测试

#### 测试指标
- 接口响应时间 < 200ms（P95）
- 并发处理能力 > 1000 QPS
- 数据库查询时间 < 100ms
- 缓存命中率 > 80%

#### 测试工具
- JMeter
- Apache Bench (ab)
- wrk

## 📝 测试脚本说明

### smoke-test.ps1
**功能**: 冒烟测试脚本
**用法**:
```powershell
.\scripts\smoke-test.ps1
.\scripts\smoke-test.ps1 -BaseUrl "http://localhost:48080"
```

**测试内容**:
- 健康检查
- 登录认证
- 核心接口功能

### quality-gate-test.ps1
**功能**: 质量门禁测试脚本
**用法**:
```powershell
.\scripts\quality-gate-test.ps1
```

**测试内容**:
- 代码质量检查
- 测试覆盖率检查
- 安全扫描检查

## 🔧 测试环境配置

### 测试数据库
```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: jdbc:mysql://localhost:3307/medicine_test
          username: root
          password: test123
```

### 测试配置
```yaml
medicine:
  security:
    mock-enable: true  # 测试环境允许Mock
  captcha:
    enable: false  # 测试环境禁用验证码
```

## 📊 测试覆盖率

### 目标覆盖率
- **整体覆盖率**: ≥ 60%
- **核心业务**: ≥ 80%
- **工具类**: ≥ 90%

### 查看覆盖率报告
```bash
# 生成报告
mvn test jacoco:report

# 查看报告
open target/site/jacoco/index.html
```
