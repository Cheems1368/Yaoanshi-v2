## 🚀 快速部署

### 环境要求
- **操作系统**: Linux (CentOS 7+/Ubuntu 18+)
- **Java版本**: JDK 11+
- **数据库**: MySQL 8.0+
- **缓存**: Redis 6.0+
- **内存**: 最小4GB，推荐8GB+
- **磁盘**: 最小50GB，推荐100GB+

### 一键启动
```bash
# 启动所有服务
docker compose up -d

# 查看服务状态
docker compose ps

# 查看日志
docker compose logs -f medicine-server
```

### 健康检查
```bash
# 检查应用状态
curl http://localhost:48080/actuator/health

# 查看应用信息
curl http://localhost:48080/actuator/info
```

## 📊 监控配置

### 系统监控
- **CPU使用率**: 监控CPU负载
- **内存使用率**: 监控内存使用情况
- **磁盘使用率**: 监控磁盘空间
- **网络流量**: 监控网络I/O

### 应用监控
- **JVM指标**: 堆内存、GC情况
- **数据库指标**: 连接数、慢查询
- **缓存指标**: 命中率、连接数
- **业务指标**: 用户数、请求量

### 告警配置
- **服务可用性**: 服务不可用告警
- **性能指标**: 响应时间超阈值告警
- **错误率**: 错误率超阈值告警
- **资源使用**: 资源使用率告警
