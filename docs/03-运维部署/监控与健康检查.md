### 🔧 健康检查增强方案

#### 1. 基础设施健康检查

**数据库健康检查**:
```java
@Component
public class DatabaseHealthIndicator implements HealthIndicator {
    
    @Autowired
    private DataSource dataSource;
    
    @Override
    public Health health() {
        try {
            // 检查数据库连接
            try (Connection connection = dataSource.getConnection()) {
                if (connection.isValid(5)) {
                    return Health.up()
                        .withDetail("database", "MySQL")
                        .withDetail("status", "Connected")
                        .withDetail("validationQuery", "SELECT 1")
                        .build();
                }
            }
        } catch (Exception e) {
            return Health.down()
                .withDetail("database", "MySQL")
                .withDetail("error", e.getMessage())
                .build();
        }
        return Health.down()
            .withDetail("database", "MySQL")
            .withDetail("error", "Connection validation failed")
            .build();
    }
}
```

**Redis健康检查**:
```java
@Component
public class RedisHealthIndicator implements HealthIndicator {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Override
    public Health health() {
        try {
            // 检查Redis连接
            String pong = redisTemplate.getConnectionFactory()
                .getConnection().ping();
            
            if ("PONG".equals(pong)) {
                return Health.up()
                    .withDetail("redis", "Connected")
                    .withDetail("ping", pong)
                    .build();
            }
        } catch (Exception e) {
            return Health.down()
                .withDetail("redis", "Disconnected")
                .withDetail("error", e.getMessage())
                .build();
        }
        return Health.down()
            .withDetail("redis", "Connection failed")
            .build();
    }
}
```

#### 2. 业务健康检查

**用药计划健康检查**:
```java
@Component
public class MedicationPlanHealthIndicator implements HealthIndicator {
    
    @Autowired
    private MedPlanMapper medPlanMapper;
    
    @Override
    public Health health() {
        try {
            // 检查用药计划服务状态
            long totalPlans = medPlanMapper.selectCount(null);
            long activePlans = medPlanMapper.selectCount(
                new QueryWrapper<MedPlanDO>().eq("status", 1));
            
            // 计算活跃率
            double activeRate = totalPlans > 0 ? 
                (double) activePlans / totalPlans * 100 : 0;
            
            return Health.up()
                .withDetail("medication", "Available")
                .withDetail("totalPlans", totalPlans)
                .withDetail("activePlans", activePlans)
                .withDetail("activeRate", String.format("%.2f%%", activeRate))
                .withDetail("status", "Normal")
                .build();
        } catch (Exception e) {
            return Health.down()
                .withDetail("medication", "Unavailable")
                .withDetail("error", e.getMessage())
                .withDetail("status", "Service error")
                .build();
        }
    }
}
```

**今日任务健康检查**:

@Component
public class TodayTaskHealthIndicator implements HealthIndicator {
    
    @Autowired
    private TodayTaskMapper todayTaskMapper;

    public Health health() {
        try {
            // 检查今日任务服务状态
            long totalTasks = todayTaskMapper.selectCount(null);

                new QueryWrapper<TodayTaskDO>().eq("status", 0));
            long completedTasks = todayTaskMapper.selectCount(
                new QueryWrapper<TodayTaskDO>().eq("status", 2));

                .withDetail("completedTasks", completedTasks)

                .withDetail("status", "Normal")
                .build();

            return Health.down()
                .withDetail("todayTask", "Unavailable")
                .withDetail("error", e.getMessage())
                .withDetail("status", "Service error")
                .build();
        }
    }
}

**打卡记录健康检查**:
```java
@Component
public class CheckinHealthIndicator implements HealthIndicator {
    
    @Autowired
    private MedCheckinMapper medCheckinMapper;
    
    @Override
    public Health health() {
        try {
            // 检查打卡记录服务状态
            long totalCheckins = medCheckinMapper.selectCount(null);
            long todayCheckins = medCheckinMapper.selectCount(
                new QueryWrapper<MedCheckinDO>()
                    .apply("DATE(checkin_time) = CURDATE()"));
            long recentCheckins = medCheckinMapper.selectCount(
                new QueryWrapper<MedCheckinDO>()
                    .ge("checkin_time", LocalDateTime.now().minusDays(7)));
            
            return Health.up()
                .withDetail("checkin", "Available")
                .withDetail("totalCheckins", totalCheckins)
                .withDetail("todayCheckins", todayCheckins)
                .withDetail("recentCheckins", recentCheckins)
                .withDetail("status", "Normal")
                .build();
        } catch (Exception e) {
            return Health.down()
                .withDetail("checkin", "Unavailable")
                .withDetail("error", e.getMessage())
                .withDetail("status", "Service error")
                .build();
        }
    }
}
```

### 📊 指标监控配置

#### 1. 业务指标收集

**用药模块指标**:
```java
@Component
public class MedicationMetrics {
    
    private final MeterRegistry meterRegistry;
    private final Counter checkinCreatedCounter;
    private final Counter taskGeneratedCounter;
    private final Timer pdfGenerationTimer;
    private final Counter notificationSentCounter;
    private final Counter notificationFailedCounter;
    
    public MedicationMetrics(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
        this.checkinCreatedCounter = Counter.builder("medication.checkin.created")
            .description("Number of checkins created")
            .register(meterRegistry);
        this.taskGeneratedCounter = Counter.builder("medication.task.generated")
            .description("Number of tasks generated")
            .register(meterRegistry);
        this.pdfGenerationTimer = Timer.builder("medication.pdf.generation.time")
            .description("PDF generation time")
            .register(meterRegistry);
        this.notificationSentCounter = Counter.builder("medication.notification.sent")
            .description("Number of notifications sent")
            .register(meterRegistry);
        this.notificationFailedCounter = Counter.builder("medication.notification.failed")
            .description("Number of notifications failed")
            .register(meterRegistry);
    }
    
    public void incrementCheckinCreated() {
        checkinCreatedCounter.increment();
    }
    
    public void incrementTaskGenerated() {
        taskGeneratedCounter.increment();
    }
    
    public void recordPdfGenerationTime(Duration duration) {
        pdfGenerationTimer.record(duration);
    }
    
    public void incrementNotificationSent() {
        notificationSentCounter.increment();
    }
    
    public void incrementNotificationFailed() {
        notificationFailedCounter.increment();
    }
}
```

**业务指标使用示例**:
```java
@Service
public class MedCheckinServiceImpl implements MedCheckinService {
    
    @Autowired
    private MedicationMetrics medicationMetrics;
    
    @Override
    public Long submitCheckin(CheckinSubmitReqDTO submitReqDTO) {
        log.info("开始提交用药打卡，患者ID: {}, 计划ID: {}", 
            submitReqDTO.getPatientId(), submitReqDTO.getMedicationPlanId());
        
        try {
            // 业务逻辑
            Long checkinId = medCheckinMapper.insert(checkinDO);
            
            // 记录指标
            medicationMetrics.incrementCheckinCreated();
            
            log.info("用药打卡提交成功，打卡ID: {}, 耗时: {}ms", 
                checkinId, System.currentTimeMillis() - startTime);
            
            return checkinId;
        } catch (Exception e) {
            log.error("用药打卡提交失败，患者ID: {}, 错误: {}", 
                submitReqDTO.getPatientId(), e.getMessage(), e);
            throw e;
        }
    }
}
```

#### 2. 监控告警配置

**关键指标阈值**:
- **响应时间**: p95 < 300ms
- **错误率**: < 1%
- **内存使用**: < 80%
- **CPU使用**: < 70%
- **数据库连接**: < 80%

**告警级别**:
- **P0**: 服务完全不可用
- **P1**: 服务部分功能异常
- **P2**: 性能指标异常
- **P3**: 业务指标异常
