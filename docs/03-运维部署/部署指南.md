# 部署指南

本文档提供系统部署的详细流程和环境配置说明。

## 📋 部署环境

### 环境要求
- **操作系统**: Linux (CentOS 7+/Ubuntu 18+)
- **Java版本**: JDK 11+
- **数据库**: MySQL 8.0+
- **缓存**: Redis 6.0+
- **内存**: 最小4GB，推荐8GB+
- **磁盘**: 最小50GB，推荐100GB+

## 🚀 部署流程

### 1. 环境准备

```bash
# 检查系统环境
./scripts/check-prerequisites.sh

# 安装依赖软件
./scripts/install-dependencies.sh

# 配置环境变量
cp env.example .env
```

### 2. 数据库部署

```bash
# 创建数据库
mysql -u root -p < sql/init.sql

# 执行数据迁移
mysql -u root -p < sql/migration.sql

# 创建索引
mysql -u root -p < sql/performance-indexes.sql
```

### 3. 应用部署

```bash
# 构建应用
mvn clean package -DskipTests

# 部署到服务器
./scripts/deploy.sh

# 启动服务
systemctl start medicine-server
```

### 4. 验证部署

```bash
# 健康检查
curl http://localhost:48080/actuator/health

# 冒烟测试
./scripts/smoke-test.sh
```

## 🐳 Docker部署

### 使用Docker Compose

```bash
# 启动所有服务
docker compose up -d

# 查看服务状态
docker compose ps

# 查看日志
docker compose logs -f medicine-server

# 停止服务
docker compose down
```

### 服务端口
- **后端API**: http://localhost:48080
- **管理后台**: http://localhost:8080
- **MySQL**: localhost:3307
- **Redis**: localhost:16379

## 🔧 配置说明

### 应用配置

**application.yaml**:
```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: jdbc:mysql://medicine-mysql:3306/medicine
          username: root
          password: ${MYSQL_ROOT_PASSWORD}
  redis:
    host: medicine-redis
    port: 6379
```

### 环境变量

**docker.env**:
```bash
MYSQL_ROOT_PASSWORD=your_password
REDIS_PASSWORD=your_password
JWT_SECRET=your_jwt_secret
```
