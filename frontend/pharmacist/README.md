# Pharmacist Web

Independent pharmacist MVP client for Yaoshian.

## Scope

- Dashboard
- Patients
- Prescriptions
- Work orders
- Profile

## Commands

```bash
npm install
npm run dev
npm run build
```

## Local runtime

- Dev port: `3003`
- API prefix: `/admin-api/**`
- Backend target: `http://localhost:48080`

## Structure

```text
src/
  app/
  modules/pharmacist/
  shared/
  views/
  router/
  layout/
```
