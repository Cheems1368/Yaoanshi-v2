# 药按时 v0.1.0 中文发布说明（候选稿）

状态：PR C 未合并，验收矩阵尚有阻断项；本文仅供审核，不代表已发布。正式 tag 和 GitHub Release 须经最终确认。

## 本版内容

- 患者端：上海时间服药计划、已服药/漏服/跳过与可选原因、24 小时更正窗口内的离线加密队列和联网重放、旧计划取消提醒同步。
- 药师端：计划草稿、版本化即时启用和停用；启用前服务端 DDI 筛查与确认；未来已服药冲突逐药选择首次执行时点；自报按时服药率 7/30 天查看与 UTF-8 BOM CSV 导出；知识测评、满意度摘要和阶段催办。
- 管理员：同租户患者监督、导出、催办和有原因的责任药师改派；临床修改与计划启停仍由责任药师执行。
- 专业通知：个人日志游标、断线分页补偿与去重、默认静音和用户主动开启的实时响铃。
- 数据：V15 增加未来剂次唯一约束、延迟生成标记、首次执行时点、测评催办唯一记录及通知提交顺序门闩；V1–V14 保持原文。

## 指标解释

“自报按时服药率”按上海自然日、截至查询时刻已到期的有效剂次计算；只有最新有效已服药记录的实际时间处于计划时点前后 60 分钟（含边界）才计入按时。没有应服剂次时显示“暂无数据”。旧按计划报表的 `completedTasks` 和 `adherenceRate` 继续表示完成次数和完成率，新增字段表达按时口径。
